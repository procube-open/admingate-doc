# 制限
AWSアクセス制御を行なう場合の制限です。

## AWS IAM コンソール
### ポリシー
AdminGateワークフローの作業申請に使用するポリシーの
- ポリシー名は、英数字と「=.@-_」で最大長 128
- ポリシーの説明は、英数字と「+=,.@-_」の文字、半角スペースのみで	最大長 1000


## 作業申請
### 作業期間
- IAMポリシーを指定した場合、作業期間は1つのみ指定できる
- IAMポリシーを指定した場合、時間指定が設定されても無視され、常に00:00:00～23:59:59となる

### IAMポリシー
- IAMポリシーの選択一覧は、作業申請者の権限や所属グループに関係なく、IAMポリシー管理に登録されている全てのポリシーが表示される（申請者の権限以上のポリシーが選択される可能性がある）
- １つの申請で指定できるポリシーの最大数は10

### 作業者（単体選択）／作業者（OU選択）
- いずれも指定されていない場合でもエラーにならない。現状は `` "saml:sub": [] `` が生成される
- 指定できる作業者数に制限がある (***TODO:*** 具体的な数字は未執筆)

:::note
ロールの信頼ポリシーの長さには制限がある「2048文字（最大4096文字：引き上げ可能）」ため、指定できる作業者数に制限ができる
:::
