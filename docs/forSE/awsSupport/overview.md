# 概要

AdminGate ワークフローの作業申請においてIAMポリシーを指定した申請を行なうことで、AWSコンソールへのアクセスを制御することができます。ここでは、その機能と設定手順について説明します。

## 機能内容

- 作業申請が承認されていなければ AWS コンソールにアクセスできない
- 作業申請で承認されたユーザのみが作業できる
- 作業では作業申請で申請されたポリシーで許可されたことのみ実施できる

なお、操作履歴は以下の方法で確認できます。
- 全ての操作は AWS Cloud Trail で記録・監視され、いつでも監査可能である
- セッションマネージャでの SSH 接続はテキストの記録が S3 に残る


## 設定手順

1. AWS IAM コンソールで、切り替え専用ロールを作成する
1. AWS IAM コンソールで、申請作業で使用するIAMポリシーを作成する
1. IDManager のIAMポリシー管理で、2.で作成したIAMポリシーを登録する
1. IDManager でワークフローの申請・承認を行なう

:::note
作業申請に指定するIAMポリシー名は、IDManagerのIAMポリシー管理で管理されています。また申請に使用するポリシー名は、IDManagerの ***ID管理 > IAMポリシー管理*** とAWS IAMコンソールの ***アクセス管理 > ポリシー*** で一致させる必要があります。

ただし、IDManagerとAWS IAMのポリシー設定は、それぞれ他方の設定を変更しても自動的に反映されるわけではありませんので、常に一致するようにメンテナンスする必要があります。
:::
